Tutor for a Week

You tutor one child in fractions: 30 turns over Monday, Wednesday and Friday, exam next Monday. You only see what the child answers. Turn on the x-ray to see inside the child’s head, or watch how the AI agents and our reference teachers taught the very same child.

The class

Each child is one of the 30 evaluation children from the Harbor runs (seeds 3001–3005). Same child, same luck, for every teacher.

What happened

How a child works

Every rule is a documented effect from learning science. With the x-ray on, the rule behind each turn lights up.

How it’s built

Every mechanism is a documented effect; where a number had to be chosen, we say so. The first version forgot in one day; a check against real Duolingo review data showed that was far too fast, so forgetting now uses the FSRS default parameters, fitted on real reviews. The agents lose in all 27 variations of the key parameters we tested.

Our own settings: massed-practice factor 0.6, prerequisite leak 5%, misconception susceptibility 40% and fix rate 70%, self-report probabilities, learn chance 30–60%.
