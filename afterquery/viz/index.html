Is it fair?

Same information

The reference sees only what the agent sees: its own actions and the child's answers. Both play through the same MCP tools in the same Harbor harness.

Every number disclosed

Giving the agent every simulator parameter does not close the gap: gemini-pro-latest 0.52 → 0.56, gemini-3.1-pro 0.55 → 0.52; the reference still wins 9 of 10 runs.

Learned, not hand-tuned

The reference is a small PPO policy trained on simulated children (never these ones). Textbook rulebooks without training score like the agents (0.56). The edge is what experience in the environment teaches.
