# Sauna Renaissance — Junction 2026

Two projects built at Junction 2026 (Helsinki, 13–15 Nov), theme "European Tech Renaissance".

| Folder | Challenge | What |
|---|---|---|
| `afterquery/` | AfterQuery — Break the Agent | An RL environment where frontier agents fall short of a reproducible reference policy |
| `spread/` | Bahn Express — Spread | A dispatcher for one simulated week of car transport in Finland |

Work in progress. Each folder will get its own README with a one-command evaluation.

## Status
- `afterquery/probe/`: early probes (small simulators played by blind agents). See `afterquery/probe/RESULTS.md`.
- `afterquery/harbor/tutor2/`: Harbor task package for running the tutor through OpenCode + MCP.
- `spread/dispatch.py`: the Spread starter, to be extended into our dispatcher.

All code here was written during the event. MIT licensed.
